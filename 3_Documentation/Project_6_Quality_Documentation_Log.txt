The rainfall raster displayed successfully over Kenya.
The raster was clipped to the Kenya boundary.
Kenya national and administrative boundaries displayed correctly above the rainfall layer.

Issue Found:
The first script caused a Console error because the full CHIRPS daily image collection was printed.
The error message said the collection query was aborted after accumulating over 5000 elements.

The script was corrected by printing only the CHIRPS dataset ID, the annual rainfall image, Kenya boundary, and the number of daily images used for 2023.

Known Limitations:
CHIRPS rainfall values are gridded estimates.
The dataset is suitable for national and regional drought analysis but not exact site-level rainfall measurement.
Rainfall uncertainty may be higher in areas with fewer ground rainfall stations.

Status:
Dataset accepted for use in Project 6 rainfall and drought analysis.

Dataset ID:

Date Accessed:
15 May 2026

WGS 84

EPSG:4326

Data Type:
Raster remote sensing dataset / vegetation index image

Bands Used:
Band 8:
Near Infrared

Band 4:
Red

Output Band:
NDVI_2023

Processing Done:
Sentinel-2 Surface Reflectance Harmonized imagery was filtered to the Kenya boundary.
Images were filtered from 2023-01-01 to 2023-12-31.
Images with CLOUDY_PIXEL_PERCENTAGE less than 20 percent were selected.
A median composite image was created.
NDVI was calculated using Band 8 and Band 4.
The NDVI raster was clipped to the Kenya boundary.
The NDVI layer was displayed using a vegetation color palette.

Quality Check:
The Sentinel-2 image collection loaded successfully.
The NDVI raster displayed successfully over Kenya.
Kenya national and administrative boundaries displayed above the NDVI layer.
The Console printed the number of Sentinel-2 images used.
The NDVI colors appeared reasonable, with low vegetation shown in brown/yellow and healthier vegetation shown in green.

Known Issues:
Some cloud or atmospheric effects may still remain even after filtering images with less than 20 percent cloud cover.
Because the layer is a yearly median composite, it may smooth out seasonal vegetation differences.

Limitations:
NDVI shows vegetation greenness but does not directly measure crop yield, food insecurity, or exact drought impact.
NDVI interpretation should be combined with rainfall data and local knowledge.
The 2023 NDVI layer is suitable for national and regional vegetation stress analysis, not detailed farm-level decisions.

Status:
Dataset accepted for use in Project 6 vegetation health and drought stress analysis.

Combined Drought Stress Priority for Kenya 2023

File Name:
Drought_Stress_CHIRPS_NDVI_Kenya_2023

Data Sources:
1. CHIRPS Daily Precipitation
2. Sentinel-2 Surface Reflectance Harmonized

Dataset IDs:
UCSB-CHG/CHIRPS/DAILY
COPERNICUS/S2_SR_HARMONIZED

Date Accessed:
15 May 2026

Coordinate System:
WGS 84

EPSG Code:
EPSG:4326

Data Type:
Classified raster decision-support layer

Input Layers:
1. Rainfall_Class
2. NDVI_Stress_Class

Output Band:
Drought_Stress_Class

Classification Used:
Class 1:
Very high drought stress priority

Class 2:
High drought stress priority

Class 3:
Moderate drought stress priority

Class 4:
Low drought stress priority

Class 5:
Very low drought stress priority

Processing Done:
CHIRPS daily rainfall images were summed to create annual rainfall for Kenya 2023.
Annual rainfall was classified into five rainfall condition classes.
Sentinel-2 imagery was used to calculate NDVI for Kenya 2023.
NDVI was classified into five vegetation stress classes.
Rainfall class and NDVI stress class values were added to create a combined score.
The combined score was reclassified into five drought stress priority classes.
The final raster was clipped and masked to the Kenya boundary.
Kenya national and administrative boundaries were displayed above the final layer.

Quality Check:
The combined drought stress layer displayed successfully inside Kenya.
The output was visually clipped to the Kenya boundary.
Supporting rainfall and NDVI layers were included in the script but turned off by default.
The drought stress priority colors appeared correctly:
Red for very high drought stress priority.
Orange for high drought stress priority.
Yellow for moderate drought stress priority.
Light green and green for lower drought stress priority.

Known Issues:
The model is simplified because it only combines rainfall and NDVI.
It does not include social vulnerability, population exposure, crop type, livestock data, soil moisture, water points, or field observations.

Limitations:
This output should be interpreted as a screening and early-warning layer, not as final ground truth.
The classification thresholds are general and may not represent all ecological zones equally.
Further validation would be needed before using the map for operational humanitarian decisions.

Status:
Dataset accepted as a major Project 6 decision-support output.
