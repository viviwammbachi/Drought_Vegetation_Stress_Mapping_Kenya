Data Type:
FeatureCollection / Administrative boundary

What is this dataset?
This dataset represents the national boundary of Kenya. It was used to define the study area for the drought and vegetation stress mapping project.

Projection:
Geographic coordinate system

Bands or columns included:
ADM0_NAME:
Country name

What does each band or column mean?
ADM0_NAME identifies the country name. In this project, the global boundary dataset was filtered where ADM0_NAME equals Kenya.

Known limitations:
The FAO GAUL 2015 boundary dataset may not reflect the most recent administrative boundary updates. It is suitable for national-level study area definition but should not be used for detailed legal boundary decisions.

Processing done:
The global country boundary dataset was filtered in Google Earth Engine to select Kenya only.

No exported file yet. The boundary was displayed in Google Earth Engine.
