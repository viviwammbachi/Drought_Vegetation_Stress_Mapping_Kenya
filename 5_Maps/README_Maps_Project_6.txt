README FOR PROJECT 6 MAP OUTPUTS

Project Title:
Drought and Vegetation Stress Mapping in Kenya Using CHIRPS Rainfall and Sentinel-2 NDVI

Prepared by:
Vivian Mbachi

Folder:
5_Maps

Purpose of this folder:
This folder stores the final exported PNG map outputs created in ArcMap 10.8 for Project 6.

Maps included:

1. Map_1_Drought_Stress_Priority_Kenya_2023.png
Description:
This map shows combined drought stress priority areas in Kenya for 2023. It was created by combining CHIRPS rainfall classes and Sentinel-2 NDVI vegetation stress classes.
Main use:
NGO-style drought monitoring and early response screening.

2. Map_2_CHIRPS_Rainfall_Classes_Kenya_2023.png
Description:
This map shows rainfall classes across Kenya for 2023 using CHIRPS daily precipitation data summed into annual rainfall and classified into five rainfall classes.
Main use:
Climate and rainfall distribution interpretation.

3. Map_3_NDVI_Vegetation_Stress_Kenya_2023.png
Description:
This map shows vegetation condition across Kenya for 2023 using Sentinel-2 NDVI classified into vegetation condition classes.
Main use:
Vegetation health, drought impact, grazing condition, and land degradation interpretation.

4. Map_4_Rainfall_NDVI_Drought_Comparison_Kenya_2023.png
Description:
This comparison map shows rainfall classes, NDVI vegetation condition, and drought stress priority side by side.
Main use:
Explaining how rainfall and vegetation patterns relate to drought stress priority.

Software used:
ArcMap 10.8

Export format:
PNG

Export resolution:
300 dpi

Main data sources:
1. CHIRPS Daily Precipitation
2. Sentinel-2 Surface Reflectance
3. FAO GAUL Boundaries

Coordinate system:
WGS 84

EPSG Code:
EPSG:4326

Quality check:
All four maps were exported successfully and visually checked after export.
