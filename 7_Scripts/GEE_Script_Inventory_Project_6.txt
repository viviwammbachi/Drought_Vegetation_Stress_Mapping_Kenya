SCRIPT UPDATE 4

Update Name:
Loaded Sentinel-2 Imagery and Calculated NDVI for Kenya 2023

Dataset Used:
Sentinel-2 Surface Reflectance Harmonized

Earth Engine Dataset ID:
COPERNICUS/S2_SR_HARMONIZED

Purpose:
Loaded Sentinel-2 imagery and calculated NDVI to assess vegetation health across Kenya.

Processing Done:
Filtered Sentinel-2 imagery to Kenya.
Filtered imagery from 2023-01-01 to 2023-12-31.
Filtered images with cloud cover less than 20 percent.
Created a median composite image.
Calculated NDVI using Sentinel-2 Band 8 and Band 4.
Clipped NDVI raster to Kenya boundary.
Displayed NDVI with Kenya national and administrative boundaries.

Classified NDVI into Vegetation Stress Classes

Dataset Used:
Sentinel-2 Surface Reflectance Harmonized

Earth Engine Dataset ID:

Purpose:
Converted raw NDVI values into simple vegetation stress classes for easier interpretation.

Reclassified NDVI into five vegetation stress classes:
Class 1: Very low vegetation / severe stress
Class 2: Low vegetation / moderate stress
Class 3: Moderate vegetation
Class 4: Healthy vegetation
Class 5: Very healthy vegetation
Displayed the classified NDVI layer with Kenya boundaries.
