Project Summary:
This project uses free climate and remote sensing data to map rainfall conditions, vegetation health, and drought stress priority areas in Kenya for 2023. CHIRPS rainfall data was used to analyze rainfall conditions, Sentinel-2 imagery was used to calculate NDVI vegetation condition, and both indicators were combined to create a drought stress priority map.

Important Limitations:
This project is a national-level screening analysis. The drought stress priority layer combines rainfall and NDVI only. It does not include population exposure, crop yield, livestock data, soil moisture, water access, poverty indicators, market prices, or field observations. The maps should therefore be interpreted as decision-support and early-warning screening outputs, not final ground-truth drought declarations.
